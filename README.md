# Critical

Free, independent USMLE Step 2 CK-style branching clinical case simulator. Not affiliated with, endorsed by, or sponsored by USMLE, NBME, FSMB, ECFMG, or any other organization.

**Play it here:** https://xairu23.github.io/Critical/

Educational tool only, not medical advice. Critical doesn't treat patients or replace a clinician - it's a study aid, nothing more. Found a mistake in a case? Open an issue on this repo.
